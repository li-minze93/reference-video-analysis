# reference-video-analysis

看一条参考视频，输出一份带证据的分析包。它负责看懂视频，不负责直接做成片。

## 它做什么

- 看完整条参考视频，理解结构、节奏、画面语言、动效和声音关系。
- 按语义时间记录变化，不只按镜头编号列清单。
- 区分可以直接复用的机制，以及必须替换的原创内容。
- 给出候选动效卡、转场卡和声音卡，供后续动效复制 Skill 使用。

## 它不做什么

- 不直接修改 Remotion 工程。
- 不渲染成片。
- 不把分析结果直接登记进 `video-refcraft/library/`。
- 不复制博主的脸、声音、文案、截图、品牌或原创素材。

## 怎么用

在 Codex 中提供一条本地参考视频，然后说：

```text
用 reference-video-analysis 分析这条视频，输出参考分析包。
```

分析结果用于决定哪些画面机制值得复用。确认后，再交给动效复制 Skill 制作新的效果卡片。
